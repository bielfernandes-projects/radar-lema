## Priority Issues Remaining

### [P2] Sticky bar usa `document.querySelector('form')` — frágil
**O que**: A sticky bar no mobile usa `document.querySelector('form')` para submeter. Se houver outro form na página, vai submeter o errado.
**Por que importa**: Bug potencial em páginas com múltiplos forms.
**Fix**: Usar `useRef` para o form e chamar `formRef.current.requestSubmit()`.
**Arquivo**: `src/pages/EventFormPage.jsx:560-570`

### [P2] Falta feedback ao excluir evento no ManageEvents
**O que**: Após excluir evento, não há confirmação visual (Snackbar ou Alert).
**Por que importa**: Viola "visibility of system status" no momento crítico de exclusão.
**Fix**: Adicionar Snackbar de sucesso após exclusão bem-sucedida.
**Arquivo**: `src/pages/ManageEvents.jsx:56-72`

## Minor Observations

1. **Sticky bar frágil**: `document.querySelector('form')` deveria ser `useRef`.
2. **Sem feedback de exclusão**: ManageEvents não confirma exclusão bem-sucedida.
3. **Acentos ainda faltando**: "Configuracoes", "Notificacoes", "Sessoes", "Acao" — todos sem acentos.
4. **Sem skeleton loading**: Todas páginas usam CircularProgress centrado.
5. **Navbar active state**: Só usa `fontWeight: 'bold'` — indicador muito sutil.
6. **EventDetail back button**: Usa `window.history.back()` — se usuário veio de link externo, navega para fora do app.
7. **Sem 404 page**: Catch-all redireciona para `/login`.
8. **Date inputs nativos**: Input type="date"/"time" tem UX inconsistente entre browsers.
9. **EventList sem scroll-to-top**: Mudar de página na paginação não faz scroll ao topo.
10. **Tema é MUI default**: `#1976d2` é a cor default do MUI. Zero identidade de marca.

## Questions to Consider

1. **Sticky bar deveria ser um componente reutilizável?** Se outras páginas precisarem de sticky actions, vale extrair para `components/StickyActionBar.jsx`.

2. **Feedback de exclusão deveria ser Snackbar ou Alert?** Snackbar é menos intrusivo, mas Alert é mais visível. Qual combina mais com o tom institucional?

3. **Acentos faltando são intencionais?** "Configuracoes" vs "Configurações" — é descuido ou convenção? Se for convenção, documentar.

4. **BottomNav aguenta crescimento?** Com 6 itens hoje, o que acontece quando adicionar perfil, notificacoes, etc? Alguns itens deveriam ir para "Mais" ou para Settings?

5. **Qual a estratégia offline para um PWA?** Não há service worker visível, sem indicador offline, sem cache. Para um PWA que targets usuários em eventos (conectividade ruim), isso é uma lacuna.

6. **MUI default theme transmite confiança institucional ou "app interno feito em 2 dias"?** O `#1976d2` é literalmente a primeira cor do `createTheme()`. Quanto effort para um tema custom que pareça Lema, não MUI demo? (Nota: usuário pediu para não mudar a cor.)
